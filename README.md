# 🎬 Netflix Clone (Frontend Project)

A responsive Netflix homepage clone built using **HTML** and **CSS**.  
This project recreates the Netflix landing page UI for learning and practice purposes.

## 🚀 Live Website
👉 **Visit Here:**  
https://rahulbansal024.github.io/netflix-clone/

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- Responsive Design

## 📸 Features
- Netflix-style hero section
- Background movie banner
- Email signup UI
- Responsive layout for different screen sizes
